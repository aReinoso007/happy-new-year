# Happy New Year Wishes App 🎉

A beautiful web application for creating and sharing personalized Happy New Year wishes. Built with React, Tailwind CSS, and featuring festive animations.

## Features

- 🌍 **Multi-language Support**: Choose between English and Spanish
- 💬 **10 Custom Messages**: Select from 10 pre-written Happy New Year messages in your chosen language
- 👤 **Personalization**: Add a recipient's name to personalize the wish
- 🔗 **Shareable Links**: The name is stored in the URL, making it easy to share with others
- 🎊 **Festive Animations**: Enjoy confetti and fireworks animations when viewing a wish
- 🎨 **Beautiful UI**: Modern, gradient-based design with smooth animations

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

## How to Use

1. **Select Language**: Choose between English or Spanish
2. **Enter Name**: Type the name of the person you're wishing a Happy New Year
3. **Choose Message**: Select one of the 10 available messages
4. **Generate**: Click "Generate Wish" to create your personalized wish
5. **Share**: Use the "Share" button to copy the link and share it with others!

## Technologies

- React 19
- Vite
- Tailwind CSS
- React Router DOM
